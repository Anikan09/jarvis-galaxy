# Reporting a vulnerability

Found a security problem? Please report it privately through GitHub's
**[Report a vulnerability](../../security/advisories/new)** button (Security tab → Advisories), not in a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply as soon as
possible, and credit in the fix if you'd like it.

The security design is described in [docs/security.md](docs/security.md).
